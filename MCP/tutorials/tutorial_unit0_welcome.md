# Unit 0 — Welcome & Onboarding

> **Course reference:** `unit0/introduction.mdx`
> **Goal:** Understand the course structure, prerequisites, pace, and how to earn a certificate.

---

## What this course is

A free, open course on **the Model Context Protocol (MCP)**, built in partnership with **Anthropic** (co-created by the MCP standard). It teaches you to connect AI models to external tools and data through MCP — from the fundamentals to deployed, production-style applications on the Hugging Face ecosystem.

---

## The syllabus at a glance

| Chapter | Topic | What you'll learn |
| ------- | ------------------------------------------- | ------------------------------------------------------------ |
| 0 | Onboarding | Set you up with the tools and platforms you'll use. |
| 1 | MCP Fundamentals, Architecture and Core Concepts | Core concepts, architecture, and components of MCP. A simple use case. |
| 2 | End-to-end Use case: MCP in Action | A simple end-to-end MCP application you can share with the community. |
| 3 | Deployed Use case: MCP in Action | A deployed MCP application using the HF ecosystem and partners' services. |
| 4 | Bonus Units | Bonus units with partners' libraries and services (optional). |

Each chapter is further split into sections and quizzes. Everything is hands-on — you build as you learn.

---

## Two certificates

| Certificate | What you need | What it shows |
|-------------|---------------|---------------|
| **Fundamentals** | Complete **Unit 1** (chapters + quizzes) | You understand MCP core concepts |
| **Completion** | Finish **Units 2 + 3** (build + deploy real apps) | You can build and deploy MCP applications |

Earn both by working through the units and passing the quizzes at the end of each unit.

---

## Prerequisites

- **Basic knowledge of AI / LLMs** — you know what a language model does and why it might need external data.
- **At least one programming language** — Python or JavaScript/TypeScript is fine. Code examples come in both.
- **Some API concepts** — you've seen HTTP endpoints, JSON, tokens.

---

## Recommended pace

- One **chapter per week**, roughly **3–4 hours per week**.
- Units 0–3 are sequential: don't skip ahead — later units build directly on earlier ones.
- Read the key concepts, follow the code examples, then run the hands-on sections yourself.

---

## Who made this course

The course is a collaboration across the HF ecosystem:

- **Gradio** — MCP servers from Python interfaces
- **Continue / Llama.cpp** — local and open-source models with MCP
- **Anthropic** — co-creators of MCP; the course exercises tool-building patterns like Claude Code servers

---

## Tools and platforms you will use

Throughout the course you'll use:

- **Hugging Face Hub** — hosted MCP server, Spaces for deployment, and model/dataset APIs
- **The MCP SDKs** — Python (`mcp` / FastMCP) and JavaScript (`@modelcontextprotocol/*`)
- **MCP Client hosts** — Claude Desktop, Cursor, VS Code + Continue, Gradio, Tiny Agents, smolagents
- **Gradio** — fast MCP server/client scaffolding
- (Unit 3) **Claude Code**, GitHub Actions webhooks, Slack, Cloudflare Tunnel
