# Tutorials — Course Companion (Unit-by-Unit)

> Derived faithfully from the **Hugging Face MCP Course** (`hf_mcp/`). These tutorials cover **exactly what the course covers** — no more, no less. The book chapters (`../chapter_*.md`) go deeper; these tutorials are the course companion.
>
> Projects (from `hf_mcp_projects.zip`) are intentionally **not** covered here — they come in a later phase.

| Tutorial | Course unit | Covers |
|----------|-------------|--------|
| `tutorial_unit0_welcome.md` | Unit 0 | Syllabus, prerequisites, certificates, pace |
| `tutorial_unit1_fundamentals.md` | Unit 1 | MCP fundamentals, architecture, protocol, capabilities, SDK, clients, HF server, Gradio, recap, quizzes |
| `tutorial_unit2_sentiment_app.md` | Unit 2 | Gradio sentiment server, clients (mcp.json/Cursor), Continue + local models, Gradio client, Tiny Agents, Lemonade |
| `tutorial_unit3_pr_agent_claude_code.md` | Unit 3 | PR Agent workflow server for Claude Code (3 modules + walkthrough) |
| `tutorial_unit3_1_pr_agent_hub.md` | Unit 3.1 | PR Agent on the Hub: setup, server, client, webhook, quizzes |

**Navigating this set:** Read Unit 0, then Unit 1 (concepts) → Unit 2 (hands-on build) → Unit 3 (advanced workflows) → Unit 3.1 (deployed use case). Each tutorial ends with the course's own quiz so you can self-check.

**Conventions used across all tutorials:**
- Code blocks are reproduced **verbatim from the course**.
- Diagrams are drawn in **Mermaid** where the course used or implied one.
- `> [!TIP]` / `> [!WARNING]` callouts mirror the course's original callouts.
- "HF" = Hugging Face. "Hub" = Hugging Face Hub.
