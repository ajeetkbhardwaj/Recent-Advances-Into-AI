# Recent Advances Into Artificial Intelligence

AI Systems can be well understood how they evolves from the core foundation of mathematics to the current state of art handling real world problem to be solved at scale from just following the following continued learning points.

1. Mathematics gave us the language to describe learning.
2. Machine learning taught computers to learn patterns from data.
3. Deep learning allowed them to learn increasingly powerful representations.
4. Attention allowed models to focus on linear relationships within large input space.
5. Transformers made large-scale sequence modeling practical.
6. Foundation models turned large-scale pretraining into general-purpose capabilities.
7. Generative and multimodal models expanded what AI could create and understand.
8. Reasoning models introduced additional computation for difficult problems.
9. RAG and context engineering connected models to information outside their parameters.
10. Tools connected models to software and the external world via function call/api etc.
11. Model serving made those capabilities usable at production scale.
12. MCP began standardizing how AI applications connect to tools and context.
13. Agents added planning, memory, observation and action.
14. Multi-agent systems allow specialized AI components to cooperate.
15. Agentic systems combine models, agents, tools, memory, infrastructure and oversight into systems capable of pursuing complex goals.

 Hence, AI Systems has evolved from some maths on black-board to the computer learning and extracting information out of data to the models that able to answer but **AI that can reliably work toward goals** —is the central theme of the current agentic-AI era.
